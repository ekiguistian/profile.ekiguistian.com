# profile.ekiguistian.com

Situs portofolio statis Eki Guistian. Dibuat dengan HTML, CSS, dan JavaScript tanpa framework atau dependensi build.

## Struktur

- `index.html` — seluruh bagian halaman dan metadata SEO
- `assets/css/styles.css` — desain responsif, warna, tipografi, dan komponen
- `assets/js/main.js` — navigasi seluler dan tahun footer
- `assets/img/favicon.svg` — ikon situs
- `CNAME` — domain kustom

## Menambahkan data profil

Pendidikan, pengalaman kerja, dan perusahaan belum diisi karena detailnya belum tersedia. Perbarui bagian `#perjalanan` di `index.html` setelah informasi tersebut siap. Proyek awal merujuk repositori GitHub publik; uraian dapat diperluas dengan studi kasus, peran, dan hasil yang telah dikonfirmasi.

AI ditandai sebagai area eksplorasi, bukan klaim pengalaman atau keahlian. Daftar teknologi saat ini dirangkum dari profil GitHub dan dapat disesuaikan.

## Menjalankan lokal

Buka `index.html` langsung di browser atau gunakan server statis apa pun. Tidak ada proses build.

## Publikasi

Situs ini siap untuk GitHub Pages. Pastikan GitHub Pages diaktifkan pada branch `main` di pengaturan repository dan DNS `profile.ekiguistian.com` diarahkan ke GitHub Pages. File `CNAME` sudah disiapkan untuk domain tersebut.
